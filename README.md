# YET ANOTHER TODO LIST
## О проекте
Привет! Это учебный проект todo листа.

Этот сервис помогает организовать дела, не потерять важное и двигаться к целям.

С помощью данного todo листа можно хранить свои задачи в удобном онлайн формате.
Лист позволяет создавать задачи с определенными датами и давать им дополнительное описание.
Также есть возможность создавать зачачи с определенным правилом повторения:
    - повтор задачи через N количество дней;
    - повтор задачи ежегодно;
    - повтор задачи в определенные дни недели;
    - повтор задачи в определенные дни месяца и определенные месяцы.

## Выполненные задачи со звездочкой
- Реализована возможность определять из переменной окружения порт при запуске сервера;
- Реализована возможность определять путь к файлу базы данных через переменную окружения;
- Реализовано вычисление следующих дат в случае дней недель и дней месяцев;
- Реализован поиск задач с помощью поисковой строки;
- Реализована аутентификация;
- Создан Docker-образ сервиса и задеплоен на Docker Hub.

(Все задачи со звездочкой были выполнены)

## Инструкция по запуску кода локально
1) Клонирование репозитория
```shell
git clone https://github.com/TuMan204/go_final_project.git
```

2) Переменные окружения

При желании можно создать `.env` файл и заполнить его по примеру в `.env.example`, либо оставить все как есть.

Вид `.env` файла должен быть примерно такой:
```shell
TODO_PORT=7540
TODO_DBFILE=scheduler.db
TODO_PASSWORD=GolangForever
```
Названия переменных менять нельзя!

3) Сборка и запуск

Для сборки и запуска сервиса предусмотрены скрипты для macOS и Linux (Windows c Git Bash):
- команда запуска скрипта для Linux (Windows c Git Bash):
```shell
./build_run_linux.sh
```
- команда запуска скрипта для macOS:
```shell
./build_run_macos.sh
```
Также можно запустить сервис с помощью команд:
```shell
go mod tidy
```
```shell
go run main.go
```

4) Запуск тестов

В директории `/tests` можно поменять настройки тестов в файле `settings.go`.

Примерный вид настроек:
 ```shell
package tests

var Port = 7540
var DBFile = "../scheduler.db"
var FullNextDate = true
var Search = true
var Token = `eyJhbGciOiJIUzI...`

```
Чтобы протестировать формирование JWT, необходимо в переменную `Token` внести JWT токен, полученный из кук.

> Чтобы запустить тесты, необходимо собрать и запустить сервис!

Команда для запуска тестов:
```shell
go test ./tests
```

5) Сборка и запуск проекта через Docker

На Docker Hub есть Docker-образ сервиса.

Его можно запустить с помощью команды:
```shell
docker run -p 7540:7540 tuman204/todo_app:v1
```

Также можно собрать образ самостоятельно и запустить его с помощью команд:
```shell
docker build --tag todo_app:v1 .
```
```shell
docker run -p 7540:7540 todo_app:v1
```
